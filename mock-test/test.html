ℹ IIT JAM Exam Instructions & Marking Scheme

1. Question Types & Marking Scheme:

  • MCQ (Multiple Choice Questions): 1 Mark (+1, -1/3) or 2 Marks (+2, -2/3). Single correct option.
  • MSQ (Multiple Select Questions): 2 Marks (+2, 0 Negative). One or more correct options. No partial marks.
  • NAT (Numerical Answer Type): 1 Mark (+1, 0 Negative) or 2 Marks (+2, 0 Negative). Enter real number answer.

2. Question Palette Legend:

  • 🟢 Green: Answered and saved.
  • 🔴 Red: Visited but not answered.
  • ⚪ Grey: Not visited yet.
  • 🟣 Purple: Marked for review (unanswered).
  • 🟣🟢 Purple with dot: Answered and marked for review (will be evaluated).
