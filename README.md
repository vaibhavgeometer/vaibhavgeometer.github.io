# vaibhavgeometer.github.io 📐

> Official website and academic portal of **Vaibhav Geometer** — featuring Differential Geometry explorations, 3D manifold visualizers, high-yield formula vaults, and the complete **IIT JAM Mathematics (MA) Topic-Wise Mock Test Series (2022–2026)**.

---

## 🌟 Highlights & Features

### 1. 🎓 IIT JAM Mathematics (MA) Mock Test Series
- **300 Official PYQs**: Authentic questions from IIT JAM 2022, 2023, 2024, 2025, and 2026 papers.
- **9 Comprehensive Syllabus Modules**:
  1. *1.1 Sequences and Series of Real Numbers* (34 Questions, 58 Marks)
  2. *1.2 Functions of One Real Variable* (54 Questions, 90 Marks)
  3. *2.1 Functions of Two or Three Real Variables* (28 Questions, 47 Marks)
  4. *2.2 Integral Calculus* (28 Questions, 46 Marks)
  5. *2.3 Differential Equations* (37 Questions, 62 Marks)
  6. *3.1 Matrices and Vector Spaces* (33 Questions, 55 Marks)
  7. *3.2 Linear Transformations and Invertibility* (25 Questions, 42 Marks)
  8. *3.3 Eigenvalues, Eigenvectors and Inner Product Spaces* (31 Questions, 52 Marks)
  9. *3.4 Groups and Finite Groups* (30 Questions, 48 Marks)
- **Authentic CBT Exam Interface**:
  - Timed examination countdown with warning indicators.
  - Multi-status Question Palette (Answered, Not Answered, Marked for Review, Answered & Review).
  - Built-in Virtual Scientific Calculator ($+$, $-$, $\times$, $\div$, $\sin$, $\cos$, $\tan$, $\ln$, $\log$, $x^y$, $\sqrt{x}$, memory registers).
  - Full Question Paper view & instant review.
  - Sectional scoring breakdown with positive/negative marks tracking.
  - Complete step-by-step LaTeX explanations and proofs.

### 2. 🌌 3D Differential Geometry Sandbox
- Real-time interactive 3D parametric manifold rendering (Möbius Strip, Torus Knots, Enneper's Minimal Surface, Hyperbolic Paraboloid, Clifford Torus).
- Live LaTeX equation display dynamically rendered with **MathJax 3**.
- Mouse/touch drag rotation and dynamic curvature/twist controls.

### 3. 📖 Core Formula & Concept Vault
- High-yield formulas, convergence tests, Green's/Stokes' theorems, Abel's formula, Jordan canonical forms, and class equations.

## 🚀 Local Preview

Simply serve the repository root with any HTTP server (or open `index.html` directly in a modern browser):

```bash
# Python 3
python -m http.server 8000

# or Node.js / npx
npx serve .
```

Open `http://localhost:8000/` in your browser.
