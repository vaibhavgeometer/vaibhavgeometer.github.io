## 🌟 Key Features

### 🏛 1. 22-Year Official Mock Test Series (2005–2026 • 885 Official PYQs)
- **Complete Historical Archive**: Every official question paper from 2005 through 2026 with high-resolution question screenshots.
- **Two Distinct Eras**:
  - **CBT Era (2015–2026)**: 60 questions per paper with authentic MCQ, MSQ, and NAT sections (100 Marks, 180 min).
  - **Classic Era (2005–2014)**: Objective papers (15 to 35 questions).
- **Verified Master Answer Keys**: Official IIT final answer keys and accepted numeric ranges across all 22 years.

### ⚡ 2. 9 Comprehensive Sub-Topic Mock Tests (2005–2026 • 794 Official PYQs)
- **Full 22-Year Historical Archive**: Every sub-topic test contains all questions on that topic from 2005 to 2026.
- **Strict IIT JAM 2027 Syllabus Alignment**: Questions are mapped strictly according to the official syllabus (`assets/Syllabus.pdf`).
- **Out-of-Syllabus Isolation**: Obsolete topics historically present before 2022 (Vector Calculus [Green's/Stokes'/Divergence theorems, flux, line integrals], Point Set Topology [open/closed sets, metric spaces, compactness, connectedness], Rings & Fields [ideals, quotient rings], Linear Programming, and Numerical Analysis) have been cleanly isolated as `Out of Syllabus` so they do not disturb preparation for IIT JAM 2027.
- **Real Exam Marking Scheme**:
  - **MCQ** (*Multiple Choice Questions*): 1 Mark ($+1, -1/3$) and 2 Marks ($+2, -2/3$).
  - **MSQ** (*Multiple Select Questions*): 2 Marks ($+2$, no negative marking, no partial credits).
  - **NAT** (*Numerical Answer Type*): 1 Mark ($+1$, no negative) and 2 Marks ($+2$, no negative).

### 📊 3. Master Categorized JSON Dataset (`assets/iit_jam_pyqs_categorized.json`)
- **Metadata-Only Structure**: Contains `year`, `question_number`, `answer`, `topic`, and `sub_topic` for all 885 questions from 2005 to 2026.
- Standardized for programmatic processing, custom practice engines, and data analytics.

### 📑 4. 14 High-Yield Formula Cheat Sheets
- Comprehensive quick-revision formula sheets covering Sequences, Series, Single & Multivariable Calculus, Ordinary Differential Equations, Linear Algebra, and Group Theory.

### 💻 5. Authentic CBT Exam Simulator
- **Live Countdown Timer**: Sectional time management with visual urgency indicators.
- **Multi-Status Question Palette**:
  - 🟢 **Answered**: Saved responses ready for scoring.
  - 🔴 **Not Answered**: Visited questions left blank.
  - ⚪ **Not Visited**: Unseen questions.
  - 🟣 **Marked for Review**: Questions flagged to revisit.
  - 🟣🟢 **Answered & Marked for Review**: Evaluated during final submission.
- **Virtual Scientific Calculator**: Built-in floating calculator with algebraic operations, trigonometric functions, logarithm, exponentiation, root, and memory registers.
- **Question Paper View**: Full-page scrollable question paper view for rapid overview.
- **Instant Analytics & Scorecard**:
  - Real-time score computation with positive and negative marking breakdown.
  - Accuracy percentage, total time spent, and performance badges.
  - Interactive filterable review (Correct, Incorrect, Unattempted).
  - Question-by-question solution review with official answer keys.

### 📄 6. Question Bank PDF & LaTeX Source
- **Official PDF**: Formatted, publication-ready topic-wise question bank with comprehensive answer keys ([View PDF](assets/Topic-Wise-Question-Bank-2022-2026.pdf)).
- **LaTeX Source**: Clean modular TeX source file ([View TeX Source](latex/question_bank_2022_2026.tex)).

## 🚀 Running Locally

This project requires **no build tools, bundlers, or dependencies**. It runs natively in any modern web browser.

### Option 1: Python 3
```bash
# From the repository root
python -m http.server 8000
```
Open `http://localhost:8000` in your browser.

### Option 2: Node.js / NPX
```bash
npx serve .
```

### Option 3: Direct Browser File
Simply open `index.html` in Chrome, Edge, Firefox, or Safari.
