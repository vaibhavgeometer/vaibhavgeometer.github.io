## 🌟 Key Features

### 🏛 Domain 1: IIT JAM Mathematics Ecosystem

#### 1. 22-Year Official Mock Test Series (2005–2026 • 885 Official PYQs)
- **Complete Historical Coverage**: Full archive of official IIT JAM Mathematics examination papers from 2005 through 2026.
- **Two Distinct Exam Eras**:
  - **Modern & CBT Era (2015–2026)**: 60 questions per paper with authentic Section A (MCQ 1M & 2M), Section B (MSQ 2M), and Section C (NAT 1M & 2M) totalling 100 Marks (180 min).
  - **Classic Era (2005–2014)**: Objective papers (15 to 35 questions per year) reflecting the foundational era of IIT JAM.
- **Verified Master Answer Keys**: All questions are mapped to official IIT final answer keys and official numerical range acceptances.
- **High-Resolution Question Paper Screenshots**: Built-in modal to inspect original cropped paper screenshots (`assets/PYQs_Screenshots/`).

#### 2. Universal PYQ Tracker & Question Bank Engine (`pyq_tracker.js`)
- **Interactive Multi-Level Filtering**:
  - Filter across all 885 questions by Year (2005–2026), Topic / Subtopic (9 topics), Question Type (MCQ, MSQ, NAT), Difficulty (Very Easy $\to$ Hardest), and Study Status.
- **Universal Semantic Search with Aliases**:
  - Search by question identifier (`2024 Q15`, `2013 7`), mathematical terminology (`differential equation`, `eigenvalue`, `abelian group`, `power series`, `riemann integration`), or question text keywords.
- **Question Card State Management**:
  - One-click status toggles: 🟢 **Solved / Correct**, 🔴 **Incorrect / Review Needed**, ⚪ **Unattempted**, and ⭐ **Bookmarked / Starred**.
  - **Custom Notes Modal**: Add persistent mathematical notes, personal tips, and alternate solution derivations to any question card.
- **Local & Cloud Persistence**:
  - Real-time auto-saving to browser `localStorage` with full backup and restore capability.

#### 3. 5-Tier Question Difficulty Engine (`pyq_difficulty.js`)
- **Standard 5-Level Taxonomy**:
  - 🟢 **Very Easy**: Foundational definitions and direct substitution questions.
  - 🔵 **Easy**: Straightforward single-concept computational questions.
  - 🟡 **Medium**: Standard multi-step exam problems requiring methodical technique.
  - 🟠 **Hard**: Advanced multi-concept synthesis problems with subtle traps.
  - 🟣 **Hardest**: High-discrimination, rank-defining benchmark problems.
- **Exam-Pattern Baseline Inference**: Automatically assigns an objective baseline difficulty based on examination structure (e.g. 1M MCQ vs 2M MCQ vs MSQ vs 1M/2M NAT) when custom user ratings are unset.
- **Custom Difficulty Overrides**: Students can adjust difficulty ratings on any question card to reflect their personal learning curve.
- **Live Difficulty Tagging in CBT**: Real-time difficulty indicator chips rendered inside the CBT exam simulator and on final scorecards.

#### 4. Daily Solving Analytics, Streaks & Topic Mastery (`stats.js`)
- **Daily Goal & Streak Tracking**:
  - Tracks today's questions solved, active daily study streaks, and all-time highest streaks.
- **Solving Velocity Metrics**:
  - Analyzes weekly and monthly solving paces with visual velocity indicators.
- **Subject Topic Mastery Radar & Bars**:
  - Granular mastery percentages computed across all 9 syllabus subtopics, breaking down accuracy rates for Real Analysis, Multivariable Calculus, ODE, Linear Algebra, and Group Theory.
- **Completion Forecasting**:
  - Projects syllabus completion dates and recommended daily quotas based on the target exam date (14 February 2027).

#### 5. Cloud Sync & Multi-Device Backup (`cloud_sync.js`)
- **Google Drive & Cloud Integration**: Seamless cloud synchronization of study progress, question statuses, test history, bookmarks, and custom notes.
- **JSON Import / Export**: One-click export of complete study state to JSON files for offline backups or transferring between devices.

#### 6. Difficulty-Aware Custom Test & PDF Generator (`custom_pdf_generator.js`)
- **Granular Customization**: Filter custom mock tests by syllabus subtopic, question count (1–100), question format (MCQ, MSQ, NAT), chronological era, and **difficulty tier** (e.g., generate an "All-Hard Linear Algebra" diagnostic test).
- **Dual Output Modes**:
  - **In-Browser LaTeX PDF Compilation**: Instant generation of publication-quality PDFs complete with cover pages, question screenshot cards, and master answer keys.
  - **Direct CBT Simulator Launch**: Test custom generated question sets in the real exam environment.

#### 7. Authentic CBT Exam Simulator (`mock-test/test.html`)
- **Dual Examination Modes**:
  - **⚡ Official Exam Mode**: Strict countdown timer with visual urgency alerts (Green $\to$ Orange $\to$ Pulsing Red), Section navigation, and submission modal.
  - **📖 Practice Mode**: Untimed exploration mode for self-paced learning and revision.
- **Interactive Question Palette**:
  - 🟢 **Answered**: Saved responses evaluated for marks.
  - 🔴 **Not Answered**: Visited questions left unanswered.
  - ⚪ **Not Visited**: Unseen questions.
  - 🟣 **Marked for Review**: Flagged questions to revisit before submission.
  - 🟣🟢 **Answered & Marked for Review**: Evaluated during final submission.
- **Virtual Scientific Calculator**:
  - Floating, draggable scientific calculator matching CBT interfaces: trigonometry, hyperbolic functions, logarithms ($\ln, \log_{10}$), powers, roots, factorials, memory registers ($MC, MR, M+, M-$), and constants ($\pi, e$).
- **Instant Analytics & Scorecard**:
  - Real-time score computation with positive and negative marking breakdown.
  - Percentage accuracy, difficulty-wise breakdown (Easy vs Medium vs Hard), total time spent, and performance evaluation badges.
  - Interactive filterable question review (All, Correct, Incorrect, Unattempted) with official answer keys.

#### 8. 56 Pre-Compiled Publication-Quality Mock Test PDFs
- **Comprehensive Offline Test Archive**: 56 complete publication-quality LaTeX-formatted PDFs stored in `assets/Mock Tests_PDF/` and cataloged in `mock_tests_manifest.json`.
- **Each Mock Test PDF Includes**:
  1. **Cover & Structure Page**: Detailed examination statistics, pattern summary, time limits, and official exam instructions.
  2. **Question Cards**: High-resolution cropped question screenshots with metadata headers (Question Number, Section, Type, Marks, Penalties, Difficulty).
  3. **Official Master Answer Key Table**: Complete answer key and scoring evaluation rubrics on final page(s).

#### 9. 27 Era-Based Subtopic Mock Tests (3 Eras × 9 Subtopics)
- **Chronological Era Practice**:
  - **Recent CBT Era (2022–2026 • 9 Tests)**: 300 modern pattern questions.
  - **CBT Era (2015–2021 • 9 Tests)**: 420 standard CBT questions.
  - **Classic Era (2005–2014 • 9 Tests)**: 165 classic objective questions.

#### 10. 9 Comprehensive Full-Archive Subtopic Mock Tests (2005–2026 • 798 PYQs)
- Master tests aggregating all 22 years of questions for each of the 9 core syllabus subtopics.
- **Out-of-Syllabus Isolation**: 87 obsolete questions from topics removed prior to 2022 (e.g., Vector Calculus [Green's/Stokes'/Divergence theorems, surface integrals], Metric Spaces / Point Set Topology, Rings & Fields, Linear Programming, and Numerical Analysis) have been cleanly isolated to avoid distractive preparation for modern exams.

#### 11. 14 High-Yield Formula Cheat Sheets
- High-yield, concise vector PDF revision cheat sheets covering Sequences, Series, Single & Multivariable Calculus, Integral Calculus, ODE, Linear Algebra, and Group Theory.

### ♟️ Domain 2: mnk games & SOTA Game Theory Ecosystem

#### 1. Lichess-Inspired Web Platform Hub (`mnk_games/index.html`)
- **Modern Minimalist Dark Design System**: High-contrast, sleek interface styled after modern competitive platforms like Lichess, utilizing pure CSS variables, custom scrollbars, and responsive CSS grids.
- **Quick Pairing Cards**: Instant 1-click presets for classic and modern variants:
  - **3×3 Tic-Tac-Toe**: Bullet ($1+0$), Blitz ($3+2$), Classical ($10+5$)
  - **4×4 (k=4) Qubic**: 3D cubic slice game
  - **7×6 (k=4) Connect Four**: Classical gravity-less vertical line grid
  - **8×8 (k=5) Gomoku**: Fast tactical Gomoku
  - **10×10 (k=5) Pente**: Balanced five-in-a-row board
  - **15×15 (k=5) Standard Gomoku**: Tournament Gomoku grid
  - **19×19 (k=5) Renju / Go Board**: Full grandmaster board
- **Interactive Open Lobby & Solved Atlas Quick View**: Browse open challenges, test theoretical tablebase openings, and inspect game status tables.
- **Quick Game Creation Modals**:
  - **Create a Game**: Custom dimensions ($m, n \in [1, 32]$), win streak ($k \in [1, 8]$), and number of players ($j \in [2, 5]$).
  - **Play vs Computer**: Choose engine difficulty (Levels 1–8), play as X / O / Random, and toggle evaluation hints.

#### 2. SOTA Analysis Board & Game-Tree Search Engine (`mnk_games/board.html`)
- **Arbitrary Configurable Geometry ($1\times 1$ to $32\times 32$, $k=1..8$, $j=2..5$)**:
  - Scales seamlessly from trivial $3\times 3$ to $15\times 15$ Gomoku, $19\times 19$ Pente, and generalized $(m,n,k,j)$ configurations.
- **Standardized $[-100, +100]$ Win Probability Evaluation Bar**:
  - Calibrated win probability model: $+100$ = 100% win for First Player ($X$), $0$ = 50–50 balanced / theoretical draw, $-100$ = 100% win for Second Player ($O$).
  - Continuous vertical gauge with red 50–50 midpoint indicator line, high-contrast borders, and board flip orientation support.
- **Horizon-Free Static Board Evaluation (`evaluateBoardState`)**:
  - Solves the $(m,n,k)$ horizon oscillation problem by evaluating center Chebyshev proximity and unblocked line segmentation on the static board, eliminating erratic score swings on theoretical draws like $(5,5,4)$.
- **Upgraded Alpha-Beta Engine with Transposition Bounds Flags**:
  - Full transposition caching with mathematical cutoff bounds (`FLAG_EXACT`, `FLAG_LOWERBOUND`, `FLAG_UPPERBOUND`) preventing unsound hash cutoffs during deep search.
- **Decisive Open $(k-1)$ Threat Detection**:
  - Examines open segments of length $k+1$ where both ends are unoccupied. Detects unstoppable double threats and decisive open $(k-1)$ streaks, preventing tactical blunders.
- **Progressive AI Thinking & Iterative Deepening**:
  - In unsolved positions, the AI thinks progressively deeper ($d=1, 2, 3, \dots, 24$), refining move evaluations, re-ranking candidate lines, and discovering tactical Principal Variations as time elapses.
  - **Thinking Time Selector**: Quick pill selector offering `1s` (blitz), `5s` (standard analysis), `10s` (deep tactical search), `30s` (grandmaster ponder), and `∞` (unlimited search).
  - **Live Engine Telemetry**: Real-time depth indicator, evaluated nodes counter, speed in kN/s, elapsed timer, animated progress bar, `Stop`/`Run` calculation toggle, and full algebraic Principal Variation sequence.
- **All-Square Evaluation Badges & MultiPV Candidate Ranking**:
  - Dynamic evaluation badges computed across every empty square for boards up to $10\times 10$, color-coded relative to the player to move (Best in green, Neutral in gray, Blunder in red).
  - MultiPV candidate moves list ranking top moves with real-time tactical annotations.
- **📊 Full Game Computer Analysis Report**:
  - Subtab in Analysis Board that reconstructs the entire game history, evaluating every ply, calculating move-by-move evaluation deltas, and classifying moves into Best, Good, Inaccuracies, Mistakes, and Blunders.

#### 3. Tournament Arena (`#tournament`)
- **Competition Formats**:
  - **Round Robin**: $1\times$ to $10\times$ cycles with Berger polygon cyclic pairing and balanced color alternation.
  - **Knockout**: Single-elimination tournament brackets with automatic seed assignment.
- **Flexible Roster Builder**:
  - Mix human participants with any combination of AI difficulty levels (Levels 1–8).
  - One-click instant presets: "8 AI Championship", "2 Humans + 5 AIs", "4 Humans Cup".
- **Live Standings & Tiebreakers**:
  - Real-time tournament table tracking Wins, Draws, Losses, Total Points, and Sonneborn-Berger tiebreak scores.
  - 1-click export of standings and match logs to clipboard and JSON.

#### 4. Competitive Offline Match Play & Precision Chess Clocks (`#play`)
- **Genuine Competitive Match Interface**:
  - Human vs Human (Pass & Play), Human vs Computer, or AI vs AI.
  - Evaluation bar and hint arrows automatically concealed in tournament mode (`playShowEval` toggle).
- **Precision Chess Clocks**:
  - Presets: Bullet ($1+0$), Blitz ($3+2$), Rapid ($5+3$), Classical ($10+5$), and Custom base + increment times.
  - Automatic time forfeit detection and flag drop banner at `00:00`.
  - Level 8 AI plays instantly in opening tablebases, smoothly budgets search time, never flags, and refrains from thinking on opponent's turn by default (optional Ponder toggle available).
- **Post-Game Terminal Banners**:
  - Clear outcome cards for "Won by Resignation", "Won on Time" (flagged), "Won by Streak of $k$", and "Game Drawn".
  - Quick resign and draw offer buttons.

#### 5. Generalized Multi-Player $(m,n,k,j)$ Games ($j=2..5$)
- Extends $(m,n,k)$-games to multi-player games with circular turn rotation:
  - Player 1 ($X$, White)
  - Player 2 ($O$, Amber)
  - Player 3 ($\blacktriangle$, Emerald)
  - Player 4 ($\blacksquare$, Sky Blue)
  - Player 5 ($\blacklozenge$, Purple)
- Multi-clock strip, multi-opponent threat detection, and custom SVG piece rendering.

#### 6. Interactive Board Editor & Frozen Obstacle Squares (`#editor`)
- **Custom Position Setup**: Place $X$, $O$, or additional player pieces on any board coordinate.
- **Frozen Barrier Squares (`#` / ❄️)**: Place impassable obstacle squares where moves cannot be made and win streaks are blocked.
- **One-Click Export**: Launch customized positions directly into the Analysis Board or Match Play mode.

#### 7. Solved Status Atlas & Research Guide
- **Verified Matrix Atlas (`solved_status_of_mnk_games.html`)**: Complete classification table for $k=1$ to $k \ge 8$ across boards up to $32\times 32$, documenting theoretical first-player wins ($X$), second-player wins ($O$), and theoretical draws. Downloadable Excel dataset included.
- **Game Theory & SOTA AI Paper (`mnk_games_theory_and_ai.html`)**: In-depth academic exposition detailing Nash strategy-stealing, Ramsey theory, Hales-Jewett theorem, Paired-Strategy draw proofs, Threat-Space Search (VCF/VCT), and Proof-Number Search.

## 🛠 Technology Stack

- **Frontend Core**: Pure HTML5, Vanilla CSS3 (Custom CSS Variables, Grid/Flexbox, Dark & Light Mode), Vanilla ES6+ JavaScript.
- **Zero Build**: Requires **no npm install, webpack, vite, or node builds** to run or deploy.
- **Search & Game-Tree AI**: Pure JavaScript Minimax / Alpha-Beta with Transposition Tables, iterative deepening, threat-space heuristics (VCF/VCT), and Chebyshev positional evaluations.
- **PDF Compilation**: Typst (`typst` Python API for publication-quality batch PDF generation) and jsPDF (`jspdf.umd.min.js` + `autotable` for in-browser on-demand compilation).
- **Math Typesetting**: [MathJax 3](https://www.mathjax.org/) configured with TeX SVG rendering.
- **Data Pipeline**: Python 3 (`PyMuPDF` / `fitz`, `typst`, `json`, `re`).
- **Hosting & CI/CD**: [GitHub Pages](https://pages.github.com/).

## 🚀 Running Locally

Because the portal is built using standard web standards without heavy build tooling, you can run it locally with any simple HTTP server:

### Option 1: Python 3
```bash
# Clone the repository
git clone https://github.com/vaibhavgeometer/vaibhavgeometer.github.io.git
cd vaibhavgeometer.github.io

# Start local server
python -m http.server 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your web browser.

```bash
npx serve .
```

Simply double-click or open `index.html` directly in Chrome, Edge, Firefox, Brave, or Safari.
