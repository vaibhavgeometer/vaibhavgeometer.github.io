Sequences & Series of Reals

Cauchy-Hadamard Radius of Convergence:
$$\frac{1}{R} = \limsup_{n \to \infty} |a_n|^{1/n} = \lim_{n \to \infty} \left|\frac{a_{n+1}}{a_n}\right|$$
Weierstrass M-Test for Uniform Convergence:
$$\text{If } |f_n(x)| \le M_n \text{ and } \sum M_n < \infty \implies \sum f_n(x) \text{ converges uniformly.}$$
🌊

Vector Calculus & Integral Theorems

Green's & Stokes' Theorem:
$$\oint_{\partial D} (P\,dx + Q\,dy) = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dA$$
Gauss Divergence Theorem:
$$\iint_{\partial V} \vec{F} \cdot \hat{n}\,dS = \iiint_V (\nabla \cdot \vec{F})\,dV$$
⚙️

Ordinary Differential Equations

Abel's Formula for Wronskian $W(x)$:
$$y'' + P(x)y' + Q(x)y = 0 \implies W(x) = W(x_0)\exp\left(-\int_{x_0}^x P(t)\,dt\right)$$
Cauchy-Euler Equidimensional Form:
$$x^2 y'' + ax y' + by = 0 \implies m(m-1) + am + b = 0 \quad (x = e^z)$$
🔢

Linear Algebra & Matrix Theory

Rank-Nullity Theorem:
$$\dim(\text{domain } V) = \operatorname{rank}(T) + \operatorname{nullity}(T)$$
Cayley-Hamilton & Minimal Polynomial:
$$\chi_A(A) = 0, \quad m_A(\lambda) \mid \chi_A(\lambda), \quad A \text{ is diagonalizable} \iff m_A(\lambda) \text{ has distinct linear factors.}$$
💎

Modern & Finite Group Theory

Lagrange's Theorem & Class Equation:
$$|G| = |Z(G)| + \sum_{i} [G : C_G(x_i)], \quad |H| \text{ divides } |G|$$
Number of Homomorphisms:
$$|\operatorname{Hom}(\mathbb{Z}_m, \mathbb{Z}_n)| = \gcd(m, n), \quad |\operatorname{Aut}(\mathbb{Z}_n)| = \phi(n)$$
📐

Multivariable Optimization

Hessian Discriminant ($D = f_{xx}f_{yy} - f_{xy}^2$):
$$D > 0, f_{xx} > 0 \implies \text{Local Min}; \quad D > 0, f_{xx} < 0 \implies \text{Local Max}; \quad D < 0 \implies \text{Saddle Point}$$
Directional Derivative:
$$D_{\hat{u}} f(x_0, y_0) = \nabla f(x_0, y_0) \cdot \hat{u}$$
